# docs-progress

## Procédure
1. Mettre à jour DEVELOPMENT_PROGRESS après chaque work package.
2. Créer ADR pour décision architecturale significative.
3. Lier tâches aux exigences du cahier.
4. Documenter fichiers/migrations/tests/risques/next step.

## Definition of Done
- Exigence du cahier identifiée.
- Implémentation compatible avec l'existant.
- Tests pertinents passants.
- Sécurité/permissions vérifiées si concernées.
- Documentation/progression mise à jour.
