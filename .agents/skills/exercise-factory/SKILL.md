# exercise-factory

## Procédure
1. Associer compétences/difficulté/provenance.
2. Supporter validation individuelle des lots IA.
3. Utiliser moteurs exacts pour correction vérifiable.
4. Mesurer accept/edit/reject des générations.

## Definition of Done
- Exigence du cahier identifiée.
- Implémentation compatible avec l'existant.
- Tests pertinents passants.
- Sécurité/permissions vérifiées si concernées.
- Documentation/progression mise à jour.
