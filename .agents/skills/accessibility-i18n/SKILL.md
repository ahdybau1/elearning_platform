# accessibility-i18n

## Procédure
1. FR/EN d'abord selon produit, autres langues configurables.
2. Labels sémantiques, clavier, contraste, tailles de texte.
3. Ne pas stocker texte UI critique uniquement dans le code si i18n existe.
4. Tester contenu pédagogique avec lecteur d'écran lorsque pertinent.

## Definition of Done
- Exigence du cahier identifiée.
- Implémentation compatible avec l'existant.
- Tests pertinents passants.
- Sécurité/permissions vérifiées si concernées.
- Documentation/progression mise à jour.
