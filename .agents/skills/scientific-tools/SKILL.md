# scientific-tools

## Procédure
1. SymPy pour symbolique, NumPy/SciPy pour numérique.
2. Valider unités/domaines/erreurs.
3. Le LLM explique le résultat du tool, il ne remplace pas le calcul.
4. Créer tests de référence numériques/symboliques.

## Definition of Done
- Exigence du cahier identifiée.
- Implémentation compatible avec l'existant.
- Tests pertinents passants.
- Sécurité/permissions vérifiées si concernées.
- Documentation/progression mise à jour.
