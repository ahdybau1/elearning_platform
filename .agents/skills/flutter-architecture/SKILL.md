# flutter-architecture

## Procédure
1. Réutiliser patterns/state management existants s'ils sont sains.
2. Séparer UI, domaine, data/services.
3. Tester mobile/tablette/desktop et dark mode/accessibilité.
4. Éviter logique métier dispersée dans les widgets.

## Definition of Done
- Exigence du cahier identifiée.
- Implémentation compatible avec l'existant.
- Tests pertinents passants.
- Sécurité/permissions vérifiées si concernées.
- Documentation/progression mise à jour.
