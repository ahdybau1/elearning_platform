# model-factory

## Procédure
1. Ne pas entraîner un foundation model from scratch par défaut.
2. RAG pour connaissance changeante ; fine-tuning pour comportement.
3. Vérifier licences dataset/poids.
4. Aucune promotion sans gates et rollback.

## Definition of Done
- Exigence du cahier identifiée.
- Implémentation compatible avec l'existant.
- Tests pertinents passants.
- Sécurité/permissions vérifiées si concernées.
- Documentation/progression mise à jour.
