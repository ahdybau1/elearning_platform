# rag-pipeline

## Procédure
1. Sources validées + provenance/licence.
2. Chunking structure-aware + metadata curriculum/permissions/version.
3. Retrieval filtré, reranking si justifié, citations.
4. Tester prompt injection et fuite inter-profils.

## Definition of Done
- Exigence du cahier identifiée.
- Implémentation compatible avec l'existant.
- Tests pertinents passants.
- Sécurité/permissions vérifiées si concernées.
- Documentation/progression mise à jour.
