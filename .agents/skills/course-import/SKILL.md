# course-import

## Procédure
1. Stocker original/checksum/provenance.
2. Extraire nativement avant OCR.
3. Structurer puis mapper curriculum/catalogue.
4. Ne jamais publier automatiquement un résultat d'extraction.

## Definition of Done
- Exigence du cahier identifiée.
- Implémentation compatible avec l'existant.
- Tests pertinents passants.
- Sécurité/permissions vérifiées si concernées.
- Documentation/progression mise à jour.
