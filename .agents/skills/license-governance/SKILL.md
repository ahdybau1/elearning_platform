# license-governance

## Procédure
1. Enregistrer source/version/licence.
2. Distinguer licence code et licence poids/dataset.
3. Bloquer contenu sans droits clairs.
4. Documenter obligations de redistribution/attribution.

## Definition of Done
- Exigence du cahier identifiée.
- Implémentation compatible avec l'existant.
- Tests pertinents passants.
- Sécurité/permissions vérifiées si concernées.
- Documentation/progression mise à jour.
