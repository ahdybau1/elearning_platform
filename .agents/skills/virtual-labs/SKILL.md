# virtual-labs

## Procédure
1. Choisir moteur spécialisé par matière.
2. Définir paramètres, unités, limites et résultats reproductibles.
3. LLM ne fabrique pas les résultats physiques/chimiques.
4. Prévoir fallback/activité sans IA.

## Definition of Done
- Exigence du cahier identifiée.
- Implémentation compatible avec l'existant.
- Tests pertinents passants.
- Sécurité/permissions vérifiées si concernées.
- Documentation/progression mise à jour.
