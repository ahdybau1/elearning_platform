# ocr-formula

## Procédure
1. OpenCV preprocessing si utile.
2. OCR texte puis formule spécialisée.
3. Parser/valider les formules avant usage.
4. Conserver confidence, bounding boxes/provenance et revue humaine.

## Definition of Done
- Exigence du cahier identifiée.
- Implémentation compatible avec l'existant.
- Tests pertinents passants.
- Sécurité/permissions vérifiées si concernées.
- Documentation/progression mise à jour.
