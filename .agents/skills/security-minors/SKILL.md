# security-minors

## Procédure
1. Minimisation données, consentement et scopes.
2. Aucune voix/image de mineur réutilisée pour entraînement sans base explicite.
3. Sanctions/modération sensibles nécessitent règles et revue humaine.
4. Secrets hors client et logs expurgés.

## Definition of Done
- Exigence du cahier identifiée.
- Implémentation compatible avec l'existant.
- Tests pertinents passants.
- Sécurité/permissions vérifiées si concernées.
- Documentation/progression mise à jour.
