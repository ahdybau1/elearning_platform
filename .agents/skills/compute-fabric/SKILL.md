# compute-fabric

## Procédure
1. Nœuds authentifiés et approuvés.
2. Scheduler respecte confidentialité, santé, capacité, priorité, quota.
3. Free tiers externes = bonus seulement.
4. Support drain/maintenance/retry/idempotence.

## Definition of Done
- Exigence du cahier identifiée.
- Implémentation compatible avec l'existant.
- Tests pertinents passants.
- Sécurité/permissions vérifiées si concernées.
- Documentation/progression mise à jour.
