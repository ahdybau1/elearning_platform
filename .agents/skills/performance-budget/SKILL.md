# performance-budget

## Procédure
1. Définir métriques p50/p95, mémoire, taille, batterie si device.
2. Profiler avant de changer architecture.
3. Éviter dépendances lourdes sans bénéfice mesuré.
4. Documenter benchmark.

## Definition of Done
- Exigence du cahier identifiée.
- Implémentation compatible avec l'existant.
- Tests pertinents passants.
- Sécurité/permissions vérifiées si concernées.
- Documentation/progression mise à jour.
